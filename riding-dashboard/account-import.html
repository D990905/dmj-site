Account archive import

Add archive sessions to your existing private account. No existing rows or files are overwritten or deleted.

1. Sign in to the existing dashboard, then enter the expected account email.

2. Select the archive folder containing dmj-archive.json and tracks/*.gpx.gz. Preparation stays local and checks every file hash.

Alternative: select dmj-archive.json and individual gzip files together (no folder upload).

3. Upload new sessions and resume incomplete imports. Each private gzip is downloaded again and verified before completion. Keep this tab open.

Unknown wind and equipment remain unset. Similar dates and partial race tracks are not treated as duplicates. Unreadable possible matches are held for review. Account changes stop processing. A stopped in-flight request may already have committed; reconnect to reconcile safely.
