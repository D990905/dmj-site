# 라이딩 대시보드 — 차트 디자인 시스템

이 문서는 `site/riding-dashboard/` 의 모든 차트가 따르는 시각 규칙을 정한다. 단일 토큰 소스는 `js/chart-theme.js`(`window.RDChartTheme`)이며, 차트는 색·폰트를 하드코딩하지 않고 이 파일에서 읽는다.

본 시스템은 대시보드 본체(라이트 테마)에만 적용한다. 전체화면 라이딩 리플레이/Video Viewer 는 의도적으로 다크 테마이며 별도 토큰(`.replay` 스코프의 `--rp-*`)을 쓴다.

## 핵심 규칙

한 차트에서 색은 **'좌우' 또는 '상태' 중 하나만** 인코딩한다. 둘 다 색으로 쓰지 않는다. 빨강·초록이 한 차트에서는 상태(잘함/못함), 다른 차트에서는 범주를 뜻하면 사용자가 오독하므로 색의 의미를 차트마다 고정한다.

- 좌우 비교 차트(바이올린·폴라 % of target·회전 상세 P/S·P/S 비교 표)는 **색 = 좌우**다. 잘함/못함은 색이 아니라 차이값·화살표·위치로 표시한다.
- 상태 차트(속도 분포 파이·지도 트랙)는 **색 = 상태**다. 좌우 구분이 필요하면 행 라벨 텍스트로 한다.

## 색 4계열

### 1. 상태색 — 성과 '잘함/못함' 전용

5단계 앵커를 쓰며, 백분위로 더 잘게 색을 줄 땐 앵커 사이를 연속 보간한다.

| 단계 | 색 | 토큰 |
|------|------|------|
| 매우좋음 | `#1FA055` | `status.veryGood` |
| 좋음 | `#7FC241` | `status.good` |
| 보통 | `#F2C20E` | `status.mid` |
| 나쁨 | `#EC8A2E` | `status.bad` |
| 매우나쁨 | `#D6453A` | `status.veryBad` |

지표별 '좋은 방향'을 반드시 반영한다 — '클수록 좋음' 일괄 가정은 금지한다. `goodness(value, direction, opts)` 가 지표값을 0~1 의 좋음 정도로 환산하고, `statusAt(g)` 가 5앵커를 보간한다. `statusColor(value, direction, opts)` 는 둘을 합친 것이다.

| direction | 의미 | 적용 지표 |
|-----------|------|-----------|
| `higher` | 클수록 좋음 | SOG · VMG · 속도 |
| `lower` | 작을수록 좋음 | 풍상 TWA |
| `twaDown` | 비단조 — 최적 ~145° 에서 멀수록 나쁨 | 풍하 TWA |
| `heel` | `|값|` 기준 작을수록 좋음 | Heel |
| `neutral` | 좋·나쁨을 단정하지 않음 → `null` 반환 | Pitch · HR |

`neutral` 은 상태색을 주지 않는다(`null`). 호출부는 범주색으로 대체한다.

### 2. 좌우색 — 포트 / 스타보드

국제 항해 표준(좌현 홍등·우현 녹등)을 따른다. 좌우 비교 차트의 시리즈/정체성 색이다.

| 쪽 | 색 | 글자용(라이트 배경) |
|----|------|----------|
| 포트(P) | `#E12B2B` `side.port` | `#C42121` `side.portInk` |
| 스타보드(S) | `#00A651` `side.starboard` | `#0B7C44` `side.starboardInk` |

dashboard.css 에도 같은 값이 `--port` / `--starboard` / `--port-ink` / `--starboard-ink` 로 있다.

### 3. 범주색 — 지표 단순 구분

좋·나쁨 의미가 없는 단순 구분용이다. **빨강·초록은 금지**다. 순서대로 `category[0..]` 를 쓴다.

`#0A2540`(navy) · `#1F8FFF`(sea blue) · `#1FB6B6`(teal) · `#6B7A8D`(slate) · `#7A5FA8`(violet, 확장) · `#C58A2E`(amber, 확장)

### 4. 심박 존색 — Z1~Z5

고정 시퀀스다. Z1 `#3D8BD4` · Z2 `#27AE60` · Z3 `#E0A100` · Z4 `#EF7D00` · Z5 `#C0392B` · 휴식 `#8295A8`. 심박 곡선 자체는 단일 시리즈 정체색(`hrZone.line` `#C0392B`, 심장=적색 관례)이며 상태 인코딩이 아니다.

## 레전드

전 차트가 동일하다. 스왓치는 사각형 1종, 위치는 차트 하단 중앙 1종, 폰트는 11px·`base.ink` 1종이다. Chart.js 차트는 `applyChartDefaults` 가 한 번에 적용한다. 커스텀 캔버스 차트(폴라·바이올린)는 같은 스왓치·폰트·색을 캔버스/HTML 범례에 그대로 쓴다.

## 축 · 격자 · 타이포

격자선은 `base.grid`(`rgba(10,37,64,0.07)`)·굵기 1px 1종이다. 축 눈금 라벨은 10px·`base.ink`, 축 제목은 11px·600·`base.ink` 1종이다. 폰트 패밀리는 `font.family` 하나로 통일한다.

## 차트 카드

`.card` 패딩·테두리는 1종이다. 카드 제목(`.card__head h3`)은 좌측·굵은 navy, 부제 eyebrow(`.card__hint`)는 우측·흐린 색 1종이다.

## 차트별 색 인코딩

| 차트 | 인코딩 | 색 계열 |
|------|--------|---------|
| 속도 분포 파이 | 속도 → 색 램프 | 상태색(higher) — `statusAt(f)` 5 앵커 (2026-06-05 옥대표님 결정: 다른 차트와 색감 통일) |
| 지도 GPS 트랙 | 속도 → 색 램프 | 상태색(higher) |
| 세션 중 심박 추이 선 | 단일 시리즈 + 존 배경 띠 | 심박 존색 |
| 심박 존 분포 막대 | 존별 막대 | 심박 존색 |
| 퍼포먼스 대비 심박 효율 | 산점/추세 2시리즈 정체색 | 범주색 |
| 윙 사이즈별 VMG 추천 막대 | 추천 강조 | 상태색(추천=좋음) |
| 세션 비교 막대/선 | 4지표 단순 구분 | 범주색 |
| 회전 상세 ±10초(P/S) | 지표=범주색 · 좌우=타일 위치+캡션색 | 범주색 + 좌우색(캡션) |
| 택/자이브 분포 바이올린 | 좌우 | 좌우색 |
| 폴라 % of target | 세션 좌우=좌우색 · 타깃=중립 점선 | 좌우색 + 중립 |

세션 비교 차트의 4지표(평균 속도·최고 속도·거리·라이딩 시간)는 좋·나쁨 의미가 없는 단순 범주이므로 범주색만 쓴다 — 빨강·초록을 쓰면 사용자가 막대를 좋고 나쁨으로 오독한다.
