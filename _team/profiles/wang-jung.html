03 · CASE STUDY

Strava Apple Watch · Native Rewrite

2022 Q1 – Q3 · 22 weeks · 8M Apple Watch 사용자
Challenge
기존 Strava Watch app 이 React Native 기반 — 평균 launch 3.2s, GPS lock 28s, 배터리 1시간 운동 = 18% 소모. App Store 리뷰 평점 3.1/5. Apple 의 새 WorkoutKit API 활용 X.
Approach
SwiftUI + WorkoutKit + HealthKit 의 native 재작성. Workout session 의 background mode 등록으로 GPS lock 28s → 4s. CoreMotion 의 sensor fusion 을 native 로 — battery 1시간 운동 18% → 6%. WidgetKit 의 complication 1차 release.
Result
Launch time 3.2s → 0.8s. GPS lock 28s → 4s. 배터리 운동 1시간 18% → 6%. App Store 평점 3.1 → 4.6. Apple 의 "Best Apps of 2022" Watch 부문 수상. Strava 사용자 watch session +180%.
