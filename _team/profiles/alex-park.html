03 · CASE STUDY

Linear · macOS Tab Bar — 60fps View Transition

2024 Q1 · 4 weeks · Linear web app · 30K MAU
Challenge
Linear 의 view tab 전환이 React state 변화 + DOM rerender 로 평균 23 fps. 사용자 체감 lag, Linear 의 "feels native" brand 와 충돌. 기존 framer-motion 사용은 bundle +47KB.
Approach
Chrome 111+ 의 View Transitions API 적용 + 구버전 fallback (graceful degradation). document.startViewTransition() 로 자동 snapshot + animate. CSS ::view-transition-old / ::view-transition-new pseudo-element 로 fine-tune. framer-motion 제거 (−47KB).
Result
Tab 전환 23 fps → 안정 60 fps (Chrome). Safari/Firefox 는 fallback 33 fps 유지. Bundle −47KB (47 → 0). Linear CEO 가 직접 "best UX shipping this quarter" 트윗.
