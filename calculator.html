Lift Calculator — takeoff 임계 속도

라이더 체중 + 프론트 윙 면적 + 풍속 + 펌핑 강도를 입력하면 takeoff v_min과 권장 윙 사이즈를 즉시 산출합니다.

입력

슈트 · 하네스 · 헬멧 · 임팩트자켓 등 착용 장비 합계 추정. default 10kg

미풍 ≤10kt → 윙 ↑ 권장 · 중풍 11-16kt (site default) · 강풍 ≥17kt → 윙 ↓ 권장

너울은 swell face 활강(중력 어시스트)으로 takeoff·글라이딩이 쉬워짐 → 페널티가 아니라 어시스트(×0.95). 초피+너울은 상쇄 ≈ 중립.

물리 모델 — CL: 저AR(<5)=1.15·중AR=1.0·고AR(>8)=0.85 / 펌핑 스킬: 마스터수준 ×0.95 (v_min 아래로 펌핑으로 부상) · 보통수준 ×1.05 · 거의 못함 ×1.15 (v_min 위 안정 부상 필요) / Gear mass = 위 입력값 (default 10kg) / ρ_water: 바다 1025 · 민물 1000 (kg/m³) / Surface: flat×1.00·choppy×1.05·swell×0.95·mixed×1.00 (swell-assist).

윙 사이즈 추천

위 입력값 기반 권장 윙 사이즈. 퍼포먼스 추천은 풍상 VMG 가 최대가 되는 윙(곡선 정점)으로 항상 메인입니다. 실사용 추천은 아래 '바람 상태' 선택을 반영합니다 — 깨끗한 바람이면 퍼포먼스 그대로, 변풍이 심할수록 더 작은(다루기 쉬운) 윙을 제시합니다.

계산식: 퍼포먼스·실사용 추천은 §181 풍상 VMG 곡선(윙 사이즈별 풍상 진척 속도)에서 직접 파생합니다 — 퍼포먼스 = 곡선 정점, 실사용 = 정점 − 변풍 오프셋(0 / 0.5 / 1.0 m²). 아래 이론 측정값은 별도 물리 진단값(최소·최대 윙, L/D, 도달 한계 등)으로, L/D 포일 = 9.13·√AR 등으로 산출됩니다.

⚠️ 이론 최대 ≠ 실제 라이딩

위 효율값(L/D)은 장비가 낼 수 있는 이론 최대치입니다. 실제 라이딩에서는 라이더의 스킬과 바람·물결 조건에 따라 50–95% 만 활용됩니다. 입문자는 약 50%, 선수 레벨은 95% 까지 활용 — 윙 어택앵글 (윙을 바람에 얼마나 비스듬히 대고 있느냐) 의 미세 조절 정밀도가 이 차이를 만듭니다. 현재 본인 스킬 활용도 = —%.

📈 윙 사이즈별 속도 곡선

📐 heel 각도별 버틸 수 있는 max 윙

풍상 진행 속도 = 해당 윙·포일·스킬·풍속 조합에서, 스킬별 풍상 진행 각도로 풍상을 올라갈 때 도달 가능한 보드 속도(SOG)입니다. 윙이 끌어주는 힘 = 포일이 받는 저항 의 균형점을 물리 모델로 계산합니다.
일반적으로 윙 ↑ → 속도 ↑ (라이더가 견딜 한계 직전까지), 윙 효율 ↑ → 속도 ↑, 스킬 ↑ → 더 가파른 풍상 진행 + 효율 ↑.
¹ "라이더 한계" 표시: 강풍·큰 윙 조합에서는 라이더가 옆으로 받는 힘이 한계에 닿아 윙이 풀 파워를 못 냅니다. 이 영역에서는 보드 속도가 윙 사이즈가 아니라 라이더의 기댐 한계로 결정 → 세 셀이 같은 값으로 수렴. 작은 사이즈가 차이를 만드는 구간은 그 직전 (윙이 자유롭게 풀파워를 낼 수 있는) 영역입니다.
스킬별 풍상 진행 각도: 입문 65° / 초급 60° / 중급 55° / 상급 50° / 선수 45° (5° 균등). 라이더 기댐 한계 (선수) 42°. 보드 속도 모델 상한 35노트.
📐 물리 모델 수식 (개발자용) V_app² = V_b² + V_t² + 2·V_t·V_b·cos(θ_tack), cos β = (V_b + V_t·cos θ_tack)/V_app, T = 0.5·ρ·V_app²·A·C_L·[sin β − cos β/(L/D_eff)], D_foil = M·g/(L/D_foil_eff), heel cap: C_L ≤ 2·M·g·tan(θ_heel)/(ρ·V_app²·A·cos β)
