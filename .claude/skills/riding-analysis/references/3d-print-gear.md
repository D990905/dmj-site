## RaceBox — 옥대표 기기는 **Micro** (2026-09-01 본인 정정)

코웍이 "25Hz CSV = Mini S" 로 추정했으나 **틀렸다. Micro 다.**
Micro 도 130분@25Hz 내장 저장이 있어서 그 추론이 안 갈렸다.

**이 정정으로 설계 전제가 통째로 바뀐다.**

| | **Micro (옥대표)** | Mini / Mini S |
|---|---|---|
| 치수 | **25 × 40 × 12 mm** (공식) | 72.05 × 80.88 × 25.60 |
| 무게 | **15 g** | 106 g |
| 방수 | 🔴 **공식 "not waterproof"** | IP54 |
| **배터리** | 🔴 **없음 — 외부 3.5~16V 필요** | 1100mAh, 20h+ |
| 전원 입력 | **2핀 헤더** | USB-C |
| 내장 저장 | 130분@25Hz | 130분@25Hz (Mini S만) |

### 무엇이 바뀌나 — 3가지

**① "충전 포트 만들지 말 것" 조언이 무효다.**
Mini 는 배터리가 20시간이라 "열 때만 열면 된다"가 성립했다. Micro 는
**배터리가 아예 없다.** 케이스가 배터리를 품고 2핀으로 전원을 넣어 줘야
하고, 그 배터리를 충전할 길도 있어야 한다. 방수 난이도가 올라간다.

**② 케이스가 방수의 100% 를 진다.**
Mini 는 IP54 라 케이스가 마진을 더하는 구조였다. Micro 는 공식적으로
방수가 아니다 — **케이스가 실패하면 그냥 젖는다.** O링이 선택이 아니다.

**③ 그런데 크기가 1/8 이라 훨씬 쉽다.**
25 × 40 × 12 mm 는 밀폐하기 좋은 크기다. 씰 둘레가 짧을수록 실패 확률이
낮다. 배터리 공간까지 잡아도 Mini 보다 작게 나온다.

### 🎯 그리고 결정적 — **이미 만들어 놓은 사람들이 있다**

코웍이 "Mini/Mini S 방수 케이스 0건" 이라고 한 그 조사에서, **Micro 용은
20건+ 이고 그중 방수를 표방한 게 3건**이었다. 남의 얘기가 아니라
**옥대표 기기 얘기였다.**

- **[Micro Enclosure USB-C Wireless Charging Waterproof](https://cults3d.com/en/3d-model/various/racebox-micro-enclosure-usb-c-wireless-charging)** ~₩3,200
  — **500mAh 배터리 내장 + Qi 무선충전 + GoPro 황동 인서트.**
  위 ①번 문제(배터리 없음 + 충전)를 통째로 푼 설계다.
  ⚠ 단 **방수 방식·필라멘트·GNSS 고려를 명시하지 않았다** — 검증 필요
- **[RACEBOX micro ultra PACKET](https://cults3d.com/en/3d-model/gadget/racebox-micro-ultra-packet)**
  — **3mm O링 방수 명시**

**→ 처음부터 그리지 말고 이 둘을 사서(합쳐 1만원 미만) 뜯어보는 게 맞다.**
남의 설계를 검증하는 게 백지에서 시작하는 것보다 빠르다.

### 확인해야 할 것 (Micro 라서 새로 생긴 질문)

1. **Micro 소비전류** — 공식 미확인. 500mAh 로 몇 시간인지가 세션 길이를 정한다
2. **2핀 헤더 피치·커넥터 규격** — 배터리 배선 설계 입력값
3. 위 두 모델의 **실제 방수 성능**(둘 다 무보증)
4. 3.5~16V 입력이면 **1S LiPo(3.7V) 직결**이 되는지, 승압이 필요한지

⚠ **Pelican 1010(내부 111×73×43)은 Micro 에 과하다.** 다만 **배터리를 같이
넣어야 하므로** 여전히 쓸 만한 1차 시험 상자다 — 안에 Micro + 보조배터리를
넣고 **위성 수신부터 확인**하는 용도로. 그게 이 프로젝트의 첫 실험이어야 한다.

⚠ 예산 영향: Micro 는 $129 로 Mini S($289)보다 싸지만 **배터리·충전 회로가
추가**된다. 총액은 크게 안 바뀐다.

## 🔴 GNSS — 케이스 설계의 진짜 제약

```
✅ 재질:  ASA 또는 PETG, 자연색·밝은색
❌ 금지:  카본파이버 충전(패러데이 케이지) / 금속·메탈릭 도료 /
          나일론(흡습→디튜닝) / 짙은 카본블랙 안료(RF 흡수)
📏 두께:  2~4mm — GPS L1 파장 190mm 대비 1~2%라 전기적으로 투명.
          두께는 RF 가 아니라 구조 강도로 정하면 된다
📐 공극:  기기 상면 ↔ 케이스 천장 최소 5mm 에어갭 (Taoglas 최소 4mm)
🚫 금속:  케이스 상반부에 인서트·나사·자석·Qi 코일 배치 금지
🧭 배치:  RaceBox 로고면이 하늘을 향하게 (공식 매뉴얼)
```
출처: [Taoglas APN-13-8-002.B](https://www.taoglas.com/assets/application-notes/Internal-GPS-Active-Patch-AntennaAPN-13-8-002.B.pdf)

## 실링

| 방식 | 현실 등급 |
|---|---|
| 프린트만 (4벽+, 저속) | IPX4 |
| + 실리콘 실런트 백업 | IP65 |
| **+ 규격 O링 + 균등 클램핑** | **IP67 목표 (무보증)** |

압축률 **15~25%**, 홈 충진율 **60~85%**(100% 금지). 실전 예: 홈 2mm × 1.5mm + CS 1.5mm.
**O링 재질 EPDM**(해수+UV 최적). NBR 은 오존/UV 취약 → 비추.

## 충전 — ⚠ Micro 는 배터리가 없다 (아래는 Mini 기준이니 참고만)

Micro 는 외부 3.5~16V 를 2핀으로 받는다. "뚜껑 개폐식이면 된다"가 성립하지
않고, **케이스가 배터리를 품어야 한다.** 아래 Qi 함정 ②(코일=안테나 옆
금속 평면)는 Micro 에도 그대로 적용된다.

## 충전 — Qi 는 함정 2개 (Mini 기준)

| 방식 | 판정 |
|---|---|
| **뚜껑 개폐, 육상에서 충전** | ⭐⭐⭐⭐⭐ **업계 표준** |
| Qi 내장 | ⭐⭐⭐ 함정 2개 |

- 🪤 **USB-C CC 저항**: Qi 리시버는 *소스*, RaceBox 는 *싱크*. USB-C 소스는
  **CC1/CC2 에 56kΩ 풀업**을 걸어야 5V/500mA 를 광고한다. 없으면 **충전이 시작 안 된다.**
- 🪤 **코일+페라이트 = 넓은 금속 평면** → 안테나 5mm 금지 규칙에 직접 걸린다.
  코일은 반드시 **케이스 바닥**(안테나 반대편).

결로 대응: 습한 곳에서 열지 말 것. **실리카겔은 선택이 아니라 필수.**

## 프린터 — 🥇 **X2D 1,099,000원** (2026-09-01 추천 변경)

**앞서 P2S 를 1순위로 했으나 바꾼다.** H2C 를 알아보다 X2D 의 필터 사양을
확인했는데, **내가 ASA 안전 항목에서 "반드시 필요하다"고 쓴 것이 X2D 에는
기본 내장이고 P2S 에는 없다.**

| 기종 | 챔버 | 필터 | 국내가 |
|---|---|---|---|
| P1S | 밀폐(수동) | 활성탄 | 629,000 |
| P2S | 밀폐(수동, 베드 110°C) | 활성탄 | 799,000 |
| **X2D** ⭐ | **능동 65°C** | **G3 + H12 HEPA + 코코넛 활성탄 3단** | **1,099,000** |
| H2C | 능동 65°C | X2D 와 동일 3단 | **약 360만~** (€2,249~) |

**왜 X2D 로 올리나 — 이유 둘 다 ASA 때문이다**

1. **능동 65°C 챔버.** 케이스 본체가 ASA 인데 P1S/P2S 의 수동 챔버에서는
   ASA 워핑이 잘 난다. 첫 프린터에서 삽질하면 프로젝트가 멈춘다.
2. **3단 필터가 기본.** 이게 결정타다. ASA 는 **VOC(스티렌)와 초미세입자를
   같이** 뿜는데 — 활성탄은 VOC 만 잡고 **초미세입자는 HEPA 가 잡는다.**
   P2S 계열의 기본 활성탄만으로는 입자가 안 걸러진다. 애프터마켓 HEPA
   업그레이드 키트가 따로 팔린다는 것 자체가 방증이다(alveo3d 등).
   → P2S 를 사도 결국 필터를 더 사야 하니 **차액 30만원이 순수 추가비가
   아니다.**

⚠ P2S 기본 필터가 활성탄 단독인지 1차 출처로 재확인 못 했다(bambulab.com
403). 다만 P2S/X2D 용 "HEPA14 + 활성탄" 업그레이드 키트가 시판된다는 건
기본이 그보다 낮다는 뜻이다.

예산이 정 빠듯하면 P2S + 외부 HEPA·활성탄 2단 + 환기로 갈 수 있다.
**무필터로 거주공간 ASA 는 금지.**

### 🔴 H2C 는 사지 말 것 (옥대표 문의, 2026-09-01)

H2C 의 존재 이유는 **다색·다소재**다 — 핫엔드 6~7개 무접촉 교체, 퍼지
낭비 없이 동시 7소재, AMS 붙이면 24 필라멘트. 카메라 4대. 약 360만원~.

**우리가 뽑을 것 중 다소재인 게 하나도 없다.** 케이스는 ASA 단일,
풋스트랩 부품은 ASA/PETG 단일, 패드가 TPU 단일, 하네스 등판이 ASA 단일.

**코덱스도 독립적으로 같은 결론**(편향 방지 위해 우리 결론을 안 알려주고
물음). "다색을 쓰지 않으므로 다중 재료 자동 전환·다중 노즐·툴체인저는
활용도가 낮다. H2C 가 의미를 갖는 건 수용성 서포트 상시 사용, TPU 가스켓
오버몰딩 반복, 생산량 때문에 교체시간이 아까울 때, 레이저가 실제로 필요할
때 정도." → **두 경로가 독립적으로 같은 답에 도달했다.**

### ⚖️ 기종 결정 — **H2S** (2026-09-01 확정)

옥대표: "신제품이 더 좋은거 아니고?" → **여기서는 아니다.**
H2 세 형제는 품질 사다리가 아니라 **용도 부채꼴**이다. 밤부 자기네
태그라인이 그걸 그대로 말한다:
H2C "멀티 소재 출력에 특화" · H2D "당신의 개인 제조 허브" ·
**H2S "궁극의 단일 노즐"**.

**결정적 사실: 셋 중 제일 싼 H2S 가 빌드볼륨이 제일 크다.**
노즐이 늘면 파킹·와이프 영역과 듀얼 모드 공유 때문에 **베드를 잡아먹는다.**

| | 노즐 | 빌드볼륨 | 가격 |
|---|---|---|---|
| **H2S** ⭐ | 단일 350°C | **340×320×340 — 밤부 전 라인업 최대** | **$1,249 / ~169만** |
| H2D | 듀얼 350°C | 300×320×325 (듀얼) / 325×320×325 (단일) | $1,999 / ~270만 |
| H2C | 6~7 핫엔드 | 305×320×325 | €2,249 / ~360만 |
| X2D | 듀얼 | 256×256×260 | $649 / 109.9만 |
| P2S | 단일 | 256×256×256 | 79.9만 |

**우리 부품은 전부 단일 소재다.** 노즐 추가분은 전액 안 쓰는 기능이고,
기구가 늘면 고장날 곳도 는다. H2D 의 레이저/커터도 우리 작업엔 없다.

**H2S 로 간다.** X2D 보다 59만 더 쓰는 값은 **하네스 등판(250×120)** 이다 —
X2D 256×256 에는 수치상만 들어가고 ASA 브림·퍼지 라인 여유가 없다.
등판을 여러 번 시행착오하며 뽑을 계획이면 이 59만이 제일 싼 보험이다.

⚠ **H2S 기본 필터 사양은 1차 출처로 확인 못 했다**(bambulab.com 403).
H2 시리즈용 애프터마켓 HEPA13/14 업그레이드 키트가 여럿 팔리는 걸 보면
기본이 활성탄 위주일 가능성이 있다.
**다만 아래 배기 항목 때문에 이건 기종 선택 기준이 아니다** — 어느 기종을
사도 배기·필터를 따로 갖춰야 한다.

### 🔴 코덱스의 교정 — 필터보다 **배기**가 먼저다

내가 "X2D 3단 필터면 ASA 안전 문제가 풀린다"고 쓴 건 과했다. 코덱스 지적:

> 데스크톱 프린터의 얇은 활성탄 패드는 질량·체류시간·누설률·교체시점과
> VOC 별 포집효율이 충분히 검증되지 않은 경우가 많다. HEPA+활성탄이
> 입자는 크게 줄이지만 **VOC 제거효율은 필터 구성에 따라 크게 달라진다.**
> 배출원 포집 또는 밀폐·배기가 주변 공기청정기보다 효과적이다.

출처: [Chemical Insights 필터 연구](https://chemicalinsights.org/wp-content/uploads/2022/04/3DP-Filtration-2021.pdf) ·
[배출 제어 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC13061758/)

**→ 기종 선택 기준이 "어느 필터냐" 가 아니라 "덕트 연결·배기 개조가 쉬운
밀폐형이냐" 로 바뀐다.** 우선순위:
1. 사람이 오래 머물지 않는 별도 방
2. 밀폐형 프린터
3. **덕트로 실외 배기**
4. 챔버 내부 HEPA + 입상 활성탄 재순환
5. 출력 후 일정 시간 배기하고 문 열기

⚠ 배기가 너무 세면 챔버가 식어 ASA 가 휜다 → 출력 중엔 약한 음압 + 내부
재순환, 종료 후 배기량을 올려 퍼지.
**침실·거실에서 배기 없이 ASA 반복 출력은 하지 말 것.**

### 코덱스가 추가로 짚은 설계 사항 (우리 조사에 없던 것)

- **O링 압착면은 출력 후 절삭·연마하거나 별도 평면 부품으로.** FDM 표면
  거칠기가 그대로 씰 누설 경로가 된다 — 이걸 안 하면 O링을 넣어도 샌다
- **배터리·기판은 컨포멀 코팅 또는 포팅**을 별도로 검토 (케이스 방수 실패
  시 2차 방어). Micro 는 배터리를 케이스가 품으므로 더 중요
- **나사 체결부의 갈바닉 부식**, 온도변화에 따른 **내부 압력·결로**
- 침수시험은 물통 담그기로 끝내지 말고 **예상 수심·충격 반영 반복시험**
- 케이스 벽 **4~6겹**, 상·하부 두께 충분히, 국부 솔리드
- **와셔는 금속을 하중 전달면에 병용** — 나사 머리 아래 최종 압축을
  프린트 플라스틱 단독으로 받게 하지 말 것 (우리가 찾은 Armstrong 티타늄
  헥스와셔 · Duotone 금속+플라스틱 와셔 병용 구조와 정확히 일치)
- 와셔·웨지에 더 높은 압축·내열이 필요하면 **PC 또는 PC 블렌드**
  (단 PC 는 UV 장기노출이 ASA 보다 불리 → 도장·코팅 필요)
- **PETG 는 70~80°C 장기 압축에서 크리프 우려** — 마운트엔 되지만
  조여 두는 부품엔 주의

**등판은 코덱스도 같은 결론**: FDM 단독 최종품 불가, 프로토타입/몰드로
쓰고 유리·탄소섬유 라미네이트. 400kgf = 3.9kN 에 충격·피로·구멍 주변
응력집중이 더해진다. 리브 뿌리·체결구·관통홀·곡률 전환부에 Z방향 박리
하중이 걸린다는 지적이 우리 "하중을 층 평면으로" 원칙보다 구체적이다.

### 대안 (국내 A/S 때문에 후순위)

**QIDI Plus4** — 305×305×280, 능동 65°C, $699. 사양 대비 싸다. 다만
국내 현장 A/S·부품수급이 불확실 → 구매 시 판매자가 **실제 국내 수리**를
하는지 부품만 보내는지 확인할 것.

**소재**: ASA 1순위(24,200~26,000/kg) · PETG 2순위(17,900~22,000) ·
TPU 95A(29,500~33,000) · 건조기 58,910 (TPU·ASA 흡습성이라 사실상 필수)
**PLA 금지**(Tg 55~65°C, 직사광 실측 77°C 에서 1시간 변형)
⚠ **TPU 는 AMS 로 못 돌린다**(PTFE 튜브 좌굴) → 어느 기종이든 AMS 콤보를
TPU 때문에 살 이유는 없다. 외부 스풀 직결.

**층간이 약축**: Z 인장 **50~75% 감소**, XY 대비 4~5배 약함.
⚠️ 카본 필라멘트는 XY 는 올라가지만 **Z 이방성이 더 나빠진다**(80~90% 초과).
→ **하중은 층 평면 방향으로 흐르게** 설계·배치.

**안전**: ASA/ABS 는 스티렌 VOC + 초미세입자 방출(0.29~113.10 μg/min).
**HEPA + 활성탄 + 환기.** 활성탄은 포화되면 재방출하니 주기 교체.

## 🟢 풋스트랩 DIY — **하십시오** (1차보다 훨씬 긍정적)

**핵심**: 상용 풋스트랩의 하중 경로는 **웨빙 → 볼트/와셔 클램프 → 보드 인서트**다.
**바느질은 하중을 안 받는다.** 형태 유지·패딩 봉합용이다.

- Armstrong: EVA + 네오프렌, **316L 스크류 + 티타늄 헥스와셔**, 와셔가 폼을 눌러 웨빙을 클램프. 홀 ø4.2mm
- Duotone: **M7×28 스크류 4개** + 금속 탑와셔 2 + **플라스틱 탑와셔·안티트위스트 인서트**
- NSI: 중간층 3.2mm 헤비듀티 웨빙 + 바닥 8mm 저밀도 EVA (상용은 트리플 덴시티)

⚠️ **패딩 생략 금지** — 얇은 스트랩으로 발뼈가 재배열된 실사용자 보고 있음.

### 웨빙 — 폴리에스터가 정답 (정량)

| | 폴리에스터 | 나일론 |
|---|---|---|
| UV 1,000h 후 유지 | **90%** | 60~70% |
| 수분 흡수 | **<0.4%** | 3~5% |
| **젖었을 때 강도 손실** | **0%** | **15%** |

**MIL-W-17337 폴리에스터 파단하중**: 25mm **907 kgf** / 38mm 1,361 / 50mm 1,814

풋스트랩 목표 250 kgf → **25mm 로 안전율 3.6배**. 충분하다.

**봉제 계산** (Practical Sailor 실측 역산, 손바느질 효율 η≈0.65):
V-92 락스티치 1스티치 유효 18.9 lbf → 풋스트랩 250 kgf 에 **29 스티치**
→ 25mm 박스-X 1개(≈30스티치)로 커버, 2~3개면 안전율 2~3배 ✅

## 🔴 하네스 — 본체는 사고, 라인만 만든다

### 실측 데이터 (wetestkites 독립 시험)

| 항목 | 값 |
|---|---|
| 카이트 하네스 실사용 하중 | **300~400 kg** |
| 훅 최소 권장 강도 | **500 kg 이상** |
| Ride Engine 훅 영구변형 시작 | 226 kg |
| Ion 스프레더바 파손 | 약 575 kg |
| **실패 보고 73건 — 거의 전부 훅 용접부** | **정적 시험에서 재현 안 됨 → 파괴는 동적·피로** |

### 계산

```
설계 최대 P = 400 kgf,  안전율 5:1 → 필요 파단 2,000 kgf ≈ 19.6 kN
교차검증: EN 566 등반슬링 22 kN, EN 1891 정적로프 22 kN — 일치
```

우리 물리 모델(83kg 일직선, 22kt·4.5㎡)의 지속 옆힘 **1.21 kN(124 kgf)** 과
같은 자릿수이며, 카이트 실측(300~400kgf)이 더 크다 — 보수적으로 400 을 쓴다.

| 웨빙 | 파단 | 안전율 | 하네스 |
|---|---|---|---|
| 국내 가방부자재 "웨빙끈" | **미표기·아크릴 혼용** | 산출 불가 | 🔴 절대 불가 |
| MIL 폴리에스터 25mm | 907 kgf | 2.3 | 🔴 불가 |
| MIL 폴리에스터 50mm | 1,814 | 4.5 | 🟠 EN 566 미달 |

**하지만 웨빙은 약한 고리가 아니다.** 실패의 대부분이 **금속 훅**이고,
정적으로 600kg 견딘 훅이 실사용에서 부러진다. 집에서 피로 시험은 불가능하다.

🔴 **결정적: 카이트/윙 하네스 본체에 적용되는 ISO/EN 규격이 존재하지 않는다.**
ISO 21853 은 퀵릴리스 전용, ISO 12401 은 윈드서핑 하네스를 명시적으로 제외.
→ 자작하면 **비교할 기준선조차 없다.**

### 🟢 하네스 **라인**은 예외 — 커뮤니티 표준 관행

윙 하네스 라인은 웨빙이 아니라 **다이니마 로프 + PU 튜브**다.
(ION = 다이니마 코어 + PU 외피 / Wingman = Gottifredi Maffioli + Festo PU + Inox 오벌링 /
Severne = 로프 + 2mm 고밀도 PU 압출 튜브, 투명해서 마모 육안 확인)

**다이니마 SK78 파단**: 3mm 997 kg / **4mm 1,465** / 5mm 2,348

```
양끝 스플라이스 루프 → 2가닥 분담, 스플라이스 효율 0.9
4mm SK78: 1,465 × 2 × 0.9 = 2,637 kgf  ✅ (목표 2,000)
3mm:        997 × 2 × 0.9 = 1,795 kgf  🟠
→ 4mm 이상
```

길이 70~90cm. ⚠️ **윙과 보드가 같은 루프에 걸려 전체를 한 번에 버릴 수 있도록
연속 다이니마 클로즈드 루프를 포함할 것.**

### 최종 판정

| | |
|---|---|
| **풋스트랩 DIY** | 🟢 **하십시오** |
| **하네스 라인 DIY (4mm 다이니마 + 튜브)** | 🟢 **해도 됩니다** |
| 하네스 웨빙 벨트 자작 | 🔴 금지 — 20kN 필요, 233스티치, 검증 불가 |
| **스프레더바·훅 자작** | 🔴 **절대 금지** |

**직설적으로**: 훅이 하중 상태에서 파손되면 **텐션 걸린 채 갑자기 풀린다.**
뾰족하게 부러진 스테인리스가 몸 앞에 있고 그대로 물에 떨어진다.
규격도 없고 시험 장비도 없고 피로 이력도 모르는 자작품으로 감수할 리스크가 아니다.
→ 하네스 본체는 구매 (카이트존 Prolimit Drift X-Light 150,000원)
