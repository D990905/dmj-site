## B. AWA · 자세 계열 (2026-09-01 논의)

옥대표: "AWA 는 실제 어택앵글을 결정한다고 봐야해서 보드 대비 스트럿의
상대적 각도를 추정하거나 비교해볼 수 있을거고, 나중에 실시간 코칭할때
실제 붐의 각도랑 보드의 정렬상태를 감지해서 당겨라 열어라 할 수 있지 않을까"

관계식: **AoA = AWA − (붐이 보드 중심선에서 벌어진 각)**

AWA 는 속도로부터 계산되므로 CWA 를 고정하면 동어반복 — 실측 r = **−0.96 ~ −0.99**(전체 상관은 0.222 로 낮아 보여서 순진하게 만들면 그럴듯한 가짜 차트가 나온다). 대신 **"속도가 변하면 붐을 얼마나 더 당겨야 하나"**(ΔAWA = Δ붐각)로 바꿔 구현. 자세 탭 상단, IMU 없어도 나옴. **발견: 풍하 트림 요구량이 풍상의 3.5배**(같은 속도폭 기준), 그리고 **풍상 요구량은 풍속에 거의 둔감**(TWS 8~20kt 에서 편차 3° 이내). selftest 19/19 |
