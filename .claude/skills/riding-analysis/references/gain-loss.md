# Gain/Loss · VMG · VMC · 기동 손실

## VMG vs VMC — 다른 것이다

| | 기준 | 식 |
|---|---|---|
| **VMG** | 바람 | `VMG = SOG × cos(TWA)` |
| **VMC** | 다음 마크 | `VMC = SOG × cos(wrap(COG − bearing_to_mark))` |

VMC 는 마크로 가까워지는 속도다. 위치가 변하면 마크 방위 β 도 변하므로
**매 샘플 다시 계산**한다. 레그 평균은 시간가중이거나 총 진행거리/경과시간.

레이스에서는 VMC 가 실전 지표지만, 우리처럼 마크가 없는 자유 라이딩에서는
VMG 가 기본이다. 코스를 정해놓고 탄 세션에서만 VMC 를 쓴다.

## Ladder rung — 거리 이득의 기준선

풍상 레그에서 "누가 앞선가"는 실제 거리가 아니라 **바람 축 방향 진행량**이다.
기준 단위벡터 u = (sin β, cos β) 를 TWD 의 풍상 방향(또는 레그 축)으로 잡고,
기준점 p₀ 에 대해

    r = (p − p₀) · u          (ladder rung 좌표)
    Gain = r_A − r_B          (두 지점/두 선수 사이의 거리 이득)
    구간 이득 = Δr_끝 − Δr_시작

옆으로 아무리 멀리 갔어도 rung 좌표가 같으면 이득은 0 이다.

**한 사람이 탈 때의 응용:** 두 택, 두 구간, 두 세션의 풍상 효율을 같은 자로
잰다. 시간당 rung 진행량 = 곧 평균 VMG 다.

## 상대 이득 (여러 명 / 여러 구간)

    Gain(t₀,t₁) = ∫ [VMG_A(t) − VMG_B(t)] dt

마크 기준이면 VMG 대신 VMC. 시작 시점에 이미 벌어져 있던 간격을 빼려면
누적값을 t₀ 에서 0 으로 정규화한다. 이게 없으면 "처음부터 앞서 있었다"가
"이득을 봤다"로 잘못 나온다.

## 기동 손실 (택/자이브에서 잃는 거리)

### 방법 A — VMG 적분 (Sailnjord 계열)

기준 VMG_ref 를 택 전 안정구간에서 잡고, 기동 구간에서 그보다 못 낸 만큼을
적분한다:

    loss = ∫ max(0, VMG_ref − VMG(t)) dt        [단위: 거리]

**Sailnjord 의 실제 창 설정** (`app.sailnjord.com/help/analytics/maneuvers.html`,
2026-08-31 확인):

- 기동 시각 = TWA 가 0°(택) / 180°(자이브) / 90°(헤드업·베어어웨이)를 **교차**하는 순간
- `Exclude Time Before/After` — 기동 준비와 회복에 걸리는 시간, 이 구간은 평균에서 뺀다
- `Average Time Before/After` — 기본 **각 20초**. 이 창에서 "이전 기준"과 "이후 비교"를 평균낸다
- 분석 시작 = 기동시각 − (Exclude Before + Average Before)
- 분석 종료 = 기동시각 + (Exclude After + Average After)
- **두 가지 손실 계산법을 나란히 보여준다** (하나로 단정하지 않는다)

### 방법 B — 위치 외삽 (반사실)

택 전 안정구간에 p_pre(t) = a + v_pre·t, 택 후에 p_post(t) = b + v_post·t 를
강건 회귀한다. "택을 안 했다면 있었을 위치"를 풍축 u 에 투영해 실제 위치와 뺀다:

    loss = [p_반사실 − p_실제] · u

A 는 계산이 쉽고 B 는 해석이 곧다. Sailnjord 가 둘 다 보여주는 이유가 있다 —
**서로 다르게 나오면 그 기동은 판정이 애매한 것이다.**

### 방법 C — 전후 최고 VMG 기준

전후 각 30초 창에서 최고 10초 평균 VMG 를 구해 기준으로 삼고

    loss = VMG_ref × 기동소요시간 − 실제 VMG 진행거리

## 기동 검출 — TWA 교차 기준

Sailnjord 기본 파라미터 (보트별로 조정 가능):

- **풍상 TWA 범위 30–60°**, **풍하 TWA 범위 120–170°**
- 택 = TWA 가 0° 교차 + 전후 |TWA| 가 풍상 범위 안
- 자이브 = 180° 교차 + 전후가 풍하 범위 안
- 헤드업/베어어웨이 = 90° 교차

윙포일은 이 범위가 다르다. 우리 실측 풍상 TWA 는 40–55° 근처, 풍하는
130–150° 근처였다 — **세션 데이터에서 확인하고 쓰되, 범위를 넓게 잡으면
리칭이 택으로 잡히고 좁게 잡으면 기동을 놓친다.**

## 택 성공률 — 공통 정의가 없다

업계 표준 정의는 확인되지 않았다. 제품마다 성공 조건이 다르다. 우리가 쓰려면
**조건을 먼저 고정하고 그 조건을 화면에 적어야 한다**:

- 최소 출구 속도 (예: 진입 속도의 x%)
- 회복 시간 상한
- **포일링 유지 여부** ← 윙포일에서는 이게 사실상 성공의 정의다

정의를 안 적고 성공률만 보여주면 세션 간 비교가 무의미해진다.

## 스타트라인 편향 (참고 — 우리 용도 아님)

    L = bearing(pin, committee)
    L₀ = wrap(TWD + 90°)
    biasAngle = wrap180(L − L₀)
    biasAdv = D × sin(biasAngle)        (D = 라인 길이)

부호로 유리한 끝을 정한다. Vakaros 등이 표시하지만 매뉴얼에 이 식을 명시하진
않았다 — 기하에서 나오는 식이다.

## 조류 (GPS 만으로는 불가능)

    v_current = v_ground − v_water
              = SOG·unit(COG) − STW·unit(Heading + Leeway)

GPS 만 있으면 v_water 를 모른다. **heading 과 수중속도(STW)가 있어야** 벡터
차로 분리된다. GPS 트랙만으로 조류를 뽑아냈다는 결과는 의심한다.
