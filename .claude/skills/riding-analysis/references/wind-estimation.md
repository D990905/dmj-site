# 진풍향(TWD) 추정 — 방법과 실패 조건

TWD 가 틀리면 그 위에 얹힌 것이 **전부** 틀린다. TWA·VMG·폴라·택 분류·
풍상 레그 검출·gain/loss 가 모두 TWD 의 함수다. 그래서 추정 방법보다
**언제 못 믿는지**가 더 중요하다.

## 방법 1 — 택 이등분 (우리 현재 방식)

양쪽 택의 안정 직선구간 COG 를 원형 평균하고, 두 평균의 이등분선을 TWD 로
잡는다. 두 이등분 후보 중 양쪽 코스가 모두 풍상 TWA 가 되는 쪽을 고른다.
회전·이상치는 중앙값이나 RANSAC 으로 뺀다.

싸고 명료하지만 아래에서 **편향된다**:

- 리칭 위주 세션 — 풍상 직선구간이 모자람
- 한쪽 택만 있는 세션 — 이등분선 자체가 성립 안 됨
- 비대칭 세팅·리웨이 — 양쪽 택의 TWA 가 애초에 다름
- **조류** — COG 는 선수방향이 아니다. 조류가 있으면 양쪽 택이 같은 방향으로
  밀려서 이등분선이 통째로 돌아간다
- 지속적 풍향 변화 — 세션 전체를 하나의 TWD 로 놓는 전제가 깨짐

## 방법 2 — typical-TWA 적합 (Sailnjord "Inferred from typical TWA")

보트가 풍상에서는 대략 이 각도, 풍하에서는 대략 저 각도로 달린다는 사전지식을
쓴다. 후보 TWD(t) 마다 각 안정구간의 TWA = wrap(COG − TWD) 를 계산하고,
풍상·풍하 typical TWA 로부터의 오차 + 시간 평활 페널티를 최소화한다:

    min  Σ ρ(|TWA_i| − TWA_typical,class)²  +  λ Σ wrap(TWD_i − TWD_{i-1})²

TWD 를 **시간에 따라 변하는 값**으로 두는 것이 이등분법과의 결정적 차이다.

Sailnjord 가 공개한 실패 조건 (`app.sailnjord.com/help/analytics/adding-wind-data.html`,
2026-08-31 확인):

> "Inference works best with clean straight upwind/downwind sailing, clear tacks
> and gybes, consistent wind direction, and good boatspeed data"

안 되는 조건은 **가볍고 변덕스러운 바람, 리칭 위주 코스, 짧고 지저분한 기동**.
이때의 처방도 공개돼 있다 — 초기 TWD 시드를 주고, 풍향이 바뀌면 세션을
나눠서 구간별로 따로 추정한다.

## 방법 3 — SAP: 기동 HMM (검증한 실제 구현)

SAP Sailing Analytics 는 Apache-2.0 로 소스가 공개돼 있다. 위키는 ML 학습
절차만 설명하고 결합식은 안 적었지만, **소스에 있다**
(`com.sap.sailing.windestimation/aggregator/hmm/ManeuverSequenceGraph.java`):

- **관측** = 기동 하나 (특징들과 함께)
- **은닉상태** = 그 기동의 종류 (택 / 자이브 / 헤드업 / 베어어웨이 / 페널티서클)
- **관측확률** = ML 분류기가 낸 기동종류 likelihood
- **전이확률** = 두 기동 사이의 TWD 변화량으로 계산. 이 변화량의 표준편차를
  **경과시간·경과거리의 함수로 회귀 학습**해 둔다 (위키의 그 회귀모델들).
  즉 "10초 사이에 풍향이 30° 돌 확률은 낮다"를 데이터로 가진다
- **Viterbi** 로 각 기동의 종류를 추론
- **Forward-Backward** 로 각 풍향 fix 의 **신뢰도**를 낸다
- MST 변형(`msthmm`)은 순차열 대신 최소신장트리를 써서 여러 보트를 함께 푼다

기동 하나는 TWD 를 한 점이 아니라 **구간**(`WindCourseRange`)으로 제약하고,
구간들을 교차시켜 좁힌다. 깨끗한 기동의 최대 코스 변화는 120° 로 자른다.

우리가 당장 훔칠 수 있는 것은 마지막 두 줄이 아니라 **구조**다:
TWD 를 세션 상수가 아니라 시간에 따라 천천히 도는 값으로 놓고, 기동마다
구간 제약을 걸고, 신뢰도를 같이 내보내는 것.

## 방법 4 — 폴라 제약 확률모델 (Vantage)

후보 상태 x_t = [TWD_t, TWS_t] 가 관측 SOG/COG 및 클래스 폴라
BSP = f(TWA, TWS) 에 부합하도록 likelihood 를 만들고, 물리 제약과 시간
연속성 prior 로 MAP 추정한다. Vantage 는 폴라 제약 모델을 쓴다고만 공개했고
목적함수·필터 종류는 비공개다.

## 방법 5 — no-go zone 축 (보조 검증용)

COG 방위별 속도 envelope E(θ) 를 만들고, 저속/결손이 연속되는 wedge 의 중심을
TWD 후보로 본다. 180° 반대 후보는 VMG 부호로 제거한다. 단독 추정기로는 약하고,
다른 방법의 답을 **검산**하는 데 쓴다.

## 실무 규칙

1. **TWD 에 신뢰도를 붙이지 않은 분석은 내보내지 않는다.** 신뢰도가 낮으면
   그 세션의 VMG·풍상각·폴라를 숫자로 단정하지 말고 그렇다고 말한다.
2. 풍향을 사용자가 입력했으면 **우리 추정치와 나란히 보여준다.** 차이가 크면
   둘 중 하나가 틀렸고, 보통은 입력 쪽이다 (§421).
3. 세션 중 풍향이 돌았다고 의심되면 **구간을 나눠 따로 추정**한다.
4. 합산 VMG 는 TWD 오차에 둔감하고 (2차), **택별** VMG 는 민감하다 (1차,
   ±10° → ±30%). 풍향을 바꿔도 종합점수가 안 변한다고 배선이 잘못된 게
   아니다 (§428).
