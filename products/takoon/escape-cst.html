takoon.com Escape 페이지 카피 — 한국 라이더 톤으로 풀어쓴 의역

접근 가능하면서도 하이퍼포먼스 — Downwind 입문 전용 보드

Escape는 downwind SUP의 한계를 밀어붙이기 위해 설계됐고, 부드러운 글라이드와 ultra-easy take-off 덕에 wingfoil에서도 빛납니다. 길쭉한 셰이프가 lift를 최대화하고 drag를 줄여 — 더 일찍 take-off, 더 멀리 비행 가능. Aerodynamic·비행 중 안정적이며, paddling·winging 모두에서 무거운 라이더나 light wind 컨디션에서도 접근 가능합니다. 3 사이즈 (110L → 135L), 입문~expert 모두 downwind foiling에서 퍼포먼스나 새 sensation을 추구하는 라이더에게 적합합니다.

Escape vs. Escape Pro

  • Escape (이 모델) — 약간 더 넓고 짧음. 가속과 안정감이 한결 좋아, 윈드 스웰·짧은 주기 파도·거친 바다에서 빠르게 띄우고 안정적으로 타고 싶을 때 적합. 최고 속도는 다소 제한 (어지러운 파도에서 편안함·반응성을 우선한 셰이프)
  • Escape Pro — 약간 더 길고 좁음. 더 민첩하고 최고 속도가 더 높음. 그라운드 스웰·긴 주기 파도에 특화 — 잠재력 끝까지 속도를 내면서도 고속에서 안정적. Escape 대비 안정성은 약간 낮지만, 길고 부드러운 파도에서 일정한 속도 유지로 보상
  • 요약 — Escape는 짧고 거친 파도에서 반응성·안정성, Escape Pro는 길고 부드러운 파도에서 고속 퍼포먼스

셰이프 (Shape · SUP race 영감)

  • Long·narrow·stretched outline — gliding 효율 최대화 + 빠른 take-off
  • 볼륨 무게중심 분배 — 정지 시 안정성 향상. balanced 분배로 stance area도 정밀화 → 라이딩 시 더 좋은 컨트롤·안정성
  • V-shaped hull — 부드러운 글라이드, progressive·fast take-off, 효율적인 water release. 자연스러운 rebound로 고속에서도 임팩트 흡수 → 편안함·forgiveness 향상

Tail · Rocker

  • V-tail + pronounced rocker — 비행 중 자유로운 움직임. pumping 시 보드가 쉽게 release (물과의 마찰점 감소). touchdown·take-off 시 V가 water flow 향상 → 더 부드럽고 다이렉트한 글라이드
  • Pronounced (그러나 과하지 않은) rocker — 부드럽고 fluid한 글라이드. swell 에너지 활용, transition·방향 전환 시 일관된 속도 유지. 매뉴버 시 안정성 손실 없이 release

구조 (Construction)

  • Ultra-Light Partial Sandwich — downwind 보드를 위해 강도 손실 없이 가능한 한 가벼운 production 보드를 목표
  • Kevlar rail 보강 — paddle 임팩트와 일상 마모로부터 보호. ultra-light·responsive·reliable
  • Molded Carbon US Box (38cm 연장, 더블 opening) — Futures 박스 대비 11cm 길어 fine-tune 자유도 ↑
  • EVA pad 3.5mm — 그립·편안함 + 데크 위 물 배수. 보드 임팩트 보호
